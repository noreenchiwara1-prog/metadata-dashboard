Person Review
Coming soon
This feature will allow you to find and verify photos where a specific person is mentioned in the caption or tags but may not actually appear in the image.
What Person Review will do
1
Search entire library for any person
Type any name. The dashboard searches all captions and tags across the entire Orange Logic library instantly using the API
2
Run Orange Logic facial recognition automatically
Uses Orange Logic's own built in facial recognition on all flagged photos. No external tools needed. Everything stays within Orange Logic
3
Sort results automatically
Confirmed correct: leave as is. Clear non-match: flag for correction. Uncertain: send to human reviewer. Only uncertain photos need human eyes
4
Apply corrections directly in Orange Logic
Removes the person's name from captions and tags where confirmed incorrect. Applied directly in Orange Logic via API. No CSV re-import needed
This feature requires the Orange Logic API connection. We are currently awaiting confirmation from Glenn and the team on API access and Orange Logic's built in facial recognition capabilities before building this feature.
